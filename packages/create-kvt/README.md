# `create-kvt`

Create a clean `core`, React `spa` or React `ssr` project with ESM and explicit
runtime bootstrap/shutdown defaults.

Every generated project includes ESLint 9, `@kvt/eslint-plugin`, Prettier and
the `lint`, `format:check` and `format` scripts. KVT rules enforce the template's
Clean Architecture dependency direction in addition to standard TypeScript and
React checks.
