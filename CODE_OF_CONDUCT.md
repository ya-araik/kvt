# Code of conduct

KVT contributors are expected to keep project spaces safe, professional and useful.

- Discuss code and ideas, not personal characteristics.
- Be constructive when reviewing work and assume good intent.
- Do not harass, threaten, discriminate against or expose private information about others.
- Respect maintainers' decisions about project scope and moderation.

Maintainers may edit or remove abusive content and temporarily or permanently restrict participation. Report conduct issues privately through the repository host's maintainer-contact or security-advisory channel.
